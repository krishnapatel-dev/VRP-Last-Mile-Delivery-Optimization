# Optimization of Last-Mile Delivery Routes using VRP

## Overview
This project focuses on optimizing delivery routes in Bengaluru using the Vehicle Routing Problem (VRP).

The system uses:
- Real-world road network data
- Statistical analysis
- Optimization algorithms
- Python visualization tools

## Technologies Used
- Python
- OSMnx
- NetworkX
- OR-Tools
- Matplotlib
- Pandas
- NumPy

## Features
- Road network extraction
- Delivery demand simulation
- Distance matrix computation
- VRP route optimization
- Statistical analysis
- Visualization of optimized routes

## Results
- Reduced delivery distance
- Improved delivery efficiency
- Better vehicle utilization

## Visualizations
- Delivery heatmap
- Distance histogram
- Optimized vehicle routes
- Comparison between random and optimized routing

## Future Improvements
- Real-time traffic integration
- Dynamic order handling
- AI-based route prediction
